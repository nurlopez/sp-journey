# sp-journey

SuperPenguin: A Little Further. A desktop keyboard game and team keepsake, 2023–2026.

## Play

After GitHub Pages is enabled, open https://nurlopez.github.io/sp-journey/ in a desktop browser at least 900 pixels wide. The invitation code is in READ-ME.txt.

Use the arrow keys to move, Space or Up to jump, Enter to continue a story, Esc to pause, and M to mute. Memories lets you reread stories as you travel. Falling keeps your collected pages.

## Website files

- `index.html` contains the complete game, including its images and current music. No installation or build is needed.
- `READ-ME.txt` contains the invitation code and playing instructions.
- `THIRD-PARTY-NOTICES.txt` contains the Phaser licence.
- `.nojekyll` tells GitHub Pages to serve the files directly.

## Enable GitHub Pages

In Settings → Pages, select Deploy from a branch, choose main and /(root), then Save.

GitHub Pages availability for private repositories depends on the account plan. Repository visibility and Pages settings are managed separately from these files.
